# memory-tests — 跨会话记忆恢复实测记录

> ⚠️ **做恢复测试时，必须排除本目录（`memory-tests/`）的内容。**
> 本目录存放题库、被测回答与评分结果。若被测 Agent 读到这里，测试即失效（等于开卷考）。
> 正确做法：用 `rec_fetch.py`（或等价方式）从远端**重新下载**仓库快照到隔离目录，目录里**不要**包含 `memory-tests/`。

## 用途

验证 Memory Architecture 的核心承诺：**一个新会话只读仓库里的 Markdown 文件，就能恢复上下文并接着干活，不依赖任何聊天历史。**

对应 `MEMORY_ARCHITECTURE.md` §9 恢复路径与 §11 验收标准（AC1 / AC2 / AC3）。

## 结构

| 路径 | 内容 |
|---|---|
| `protocol.md` | 测试协议：方法、题库（S1/S2/S3）、通过线、评分口径。**每次测试前预登记，跑测中不再改。** |
| `run-YYYY-MM-DD/` | 一次实测的完整记录：三个被测 Agent 的回答、评分、发现、修复、复验。 |

## 复现步骤

1. 从远端下载 agent-lab 快照到隔离目录（**排除 `memory-tests/`**）。
2. 按 `protocol.md` 的 S1/S2/S3 启动三个全新上下文 Agent，分别只给对应隔离目录。
3. 逐题对照通过线评分，记录 FABRICATED / NOT_RECOVERABLE。
4. 对每条未通过项定位文件缺陷 → 修复 → 重跑该题复验。
5. 把回答、评分、发现、修复写入 `run-<今日>/`。
